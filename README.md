## 📂 QA Projects

### 🏠 Airbnb Web Application — Manual Testing

**Project Type:** Manual Testing  
**Application:** [Airbnb](https://www.airbnb.com)  
**Status:** Completed

#### 📌 Overview

Performed manual testing of the Airbnb web application to evaluate core functionalities, verify expected behavior, and identify potential defects across key user workflows.

#### 🎯 Testing Objectives

- Verify that core application features function as expected.
- Validate user inputs and form behavior.
- Test search functionality, filters, and date selection.
- Evaluate user account and wishlist functionality.
- Document test execution results and unexpected behavior.

#### 🔍 Testing Scope

- **User Authentication:** Signup, login, logout, and session persistence.
- **Accommodation Search:** Destination search and search result validation.
- **Date Selection:** Check-in/check-out selection and date validation.
- **Guest Management:** Adding and removing adults, children, infants, and pets.
- **Search Filters:** Property type, amenities, price range, and multiple filters.
- **Property Details:** Property information, amenities, reviews, host information, and availability.
- **Reservation Workflow:** Date and guest modifications and progression to the next reservation stage.
- **Wishlist:** Saving and removing properties and verifying saved items.

#### 📄 Deliverables

- Documented test cases with preconditions, test steps, test data, and expected results.
- Test execution results.
